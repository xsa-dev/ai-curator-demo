# Публикация и обновление через GitHub/Vercel

- [ ] Создан GitHub-репозиторий с исходниками.
- [ ] Проект импортирован в Vercel и доступен по публичной ссылке.
- [ ] Отдельная feature branch содержит поиск по предпочтениям и его тесты.
- [ ] Получен и сохранён URL намеренно неуспешного GitHub Actions в feature branch.
- [ ] Ошибка исправлена; сохранён URL успешного GitHub Actions.
- [ ] Создан PR в main; все проверки прошли.
- [ ] Проверен Preview Deployment.
- [ ] PR объединён; проверено автоматическое обновление production.

Подтверждения для сдачи: URL приложения, GitHub-репозитория, объединённого PR, красного и зелёного workflow runs. Не объединять PR с падающими проверками.
